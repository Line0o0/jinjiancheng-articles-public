# jinjiancheng-articles-public

这个仓库整理了公开发布的微信文章正文及其公开评论，便于阅读、检索和长期归档。

## 来源

文章来自公开微信公众号文章页面及其公开评论区。文件名中的账号标识用于区分来源账号：

- `jinjiancheng`
- `tianji-qitan`
- `shengjibobo`

本仓库只保留适合公开归档的正文和评论文本，不包含抓取原始数据、会话信息、Cookie、Token、OpenID、UnionID、本地路径、脚本、笔记、Wiki 或二次加工资料。

## 亮点

不同于只归档文章正文的版本，这个仓库保留了文章评论区。

评论通常包含读者反馈、追问、作者回复、补充说明和当时的语境。对理解文章原意、判断观点形成过程、检索问答线索都很有价值。

评论昵称按公开评论中的显示昵称保留；明显敏感信息会被脱敏，例如手机号、邮箱、身份证号、微信号、QQ 号、裸链接和 `@` 提及等。

## 文件命名

文件名格式：

```text
YYYY-MM-DD_HHMM_account_mid-idx.txt
```

示例：

```text
2026/2026-07-03_0956_jinjiancheng_2247485175-1.txt
```

字段含义：

- `YYYY-MM-DD`: 发布日期
- `HHMM`: 发布时间
- `account`: 来源账号标识
- `mid-idx`: 微信文章标识

## 文件内容

每个 `.txt` 文件由两部分组成：

```text
文章正文

---- COMMENTS ----

评论区内容
```

如果文章没有可归档评论，评论区会显示：

```text
暂无评论
```
